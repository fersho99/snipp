# SNIPP: plataforma web

Panel para Jefe, Empleado y Administrador (React 19 + Tailwind CSS 4 + React Router, con Vite). La documentación de los lotes está en [`../README.md`](../README.md).

```bash
npm install
npm run dev      # http://localhost:5173 ; en "/" está el índice de pantallas y estados
npm run build    # compila a dist/
npm run lint
```
